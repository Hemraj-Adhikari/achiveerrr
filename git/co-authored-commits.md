# Co-authored commits

**Date:** 2026-10-12
**Tags:** git, github, collaboration

## What I learned

When two people worked on a change, add a `Co-authored-by` trailer at the end of the commit message so both get credit on GitHub.

## Example

```
git commit -m "Add attendance report export

Co-authored-by: Name <12345+username@users.noreply.github.com>"
```

The trailer must be after a blank line at the end of the message. Use this only when the person genuinely contributed.

## Why it matters

Credit is shown on the commit and in the contributors' profiles.
